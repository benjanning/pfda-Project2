05 / EVIDENCE WITH CONTEXT

Useful comparison. Limited conclusions.

All 30 features are retained. Seed 40 fixes the stratified split. Logistic regression scales features inside each training fold; the tree and forest use fixed seeds. Five-fold cross-validation uses training data only.

These models and portfolio iterations have repeatedly reused the same holdout. The figures are exploratory, not an unbiased ranking or evidence of real-world clinical performance. There is no independent cohort, calibration study or clinical validation.

The baseline predicts the majority class in the training labels, without consulting holdout performance. Model controls do not tune thresholds, select features or retrain.
